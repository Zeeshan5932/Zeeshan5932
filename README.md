# Zeeshan Younas — AI Engineer Portfolio

A custom, responsive, black-and-gold portfolio created from `Zeeshan_Younas_CV.pdf`.

## Quick start

1. Extract the ZIP archive.
2. Open `index.html` in your browser. No installation or build process is needed.
3. Internet access is optional; custom Google Fonts load online, but the site works with fallback fonts offline.

## What's included

- Elegant black-and-gold responsive layout
- Animated hero visualization, particle network, orbit rings, subtle hover details and scroll reveals
- About section and results-based highlights
- Skills and technology stack
- Four project showcases with illustrative UI visuals and functional category filters
- Work experience, Kaggle achievement, hackathon award and education
- Email contact button, email-copy feature, social links and CV download
- Keyboard-accessible navigation and reduced-motion support

## Files

- `index.html` — portfolio content and layout
- `styles.css` — styles, responsive rules, and animations
- `script.js` — interactive features
- `assets/favicon.svg` — brand icon
- `assets/Zeeshan_Younas_CV.pdf` — downloadable resume

## Customize

Edit `index.html` to update the biography, projects, contact details and social links.
Update the `:root` color variables at the top of `styles.css` to change the color palette.
Place images in `assets` if you want to replace the CSS-rendered conceptual project interfaces with real project screenshots.

## Publish

This is a static website. You can deploy it without changes on GitHub Pages, Netlify, Cloudflare Pages, or Vercel. Upload the **contents** of this folder (with `index.html` at the root).

## Important project-link note

The original CV contains placeholder GitHub URLs for some individual projects (`your-username`). These were not included as live links. The portfolio links to the verified GitHub, LinkedIn and Kaggle profiles from the CV instead. Add actual project repository and demo URLs when available.

All project dashboard illustrations shown on the site are **illustrative visual mockups** — they are not screenshots of live products. SteelSight AI is correctly marked **in development**.

The contact button opens the visitor's email application; no backend contact form or mail delivery service is included.
